# Security

Please report a vulnerability privately: through GitHub's "Report a vulnerability" on this
repository's Security tab, or by email to security@lumovi.dev. Don't open a public issue for it.

A vulnerability here is anything that would let a plugin do more than its file says, let a release
carry anything its checks didn’t see, or let anything be signed as a release of this repository
that didn’t pass its checks, or that wasn’t built from main by the release workflow. A plugin that’s only wrong (a column that shows nothing, a status
read the wrong way) is an issue: open one.
